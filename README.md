# konj.101 — وبلاگ شخصی (کنج ۱۰۱)

وبلاگ روانشناسی و خلاصه‌ی کتاب، با پنل مدیریت. روی Cloudflare Workers اجرا می‌شه و دیتابیسش D1 است.

## چطور این آپدیت رو بالا بیارم؟ (بدون دستور)

1. فایل زیپ رو توی کامپیوتر **اکسترکت** کن (Extract).
2. توی گیت‌هاب برو به ریپازیتوری `after-the-last-page` ← **Add file** ← **Upload files**.
3. **محتوای** پوشه‌ی اکسترکت‌شده رو (پوشه‌های `src` و `public` و فایل‌های `wrangler.jsonc` و `package.json` و `schema.sql` و `README.md`) بکش توی صفحه. خود پوشه‌ی بیرونی رو نکش.
4. پایین صفحه **Commit changes** رو بزن.
5. (پیشنهادی) دو فایل قدیمی رو پاک کن، چون دیگه لازم نیستن: توی ریپازیتوری برو `public/index.html` رو باز کن ← آیکن سطل زباله ← Commit. همین کار رو برای `public/page.html` هم بکن. (اگه پاک نکنی هم مشکلی پیش نمیاد.)
6. کلادفلر خودش بیلد جدید می‌سازه. بعد از ۱–۲ دقیقه توی Workers & Pages ← پروژه‌ات ← **Deployments** باید سبز بشه.

**نیازی به اجرای دستور SQL نیست.** سایت خودش جدول‌ها رو به‌روز می‌کنه و نوشته‌های قبلیت سالم می‌مونن. رمز و تنظیمات کلادفلر (Secrets) هم همون قبلیه.

## امکانات جدید

- **اسم سایت**: konj.101. هر وقت خواستی از پنل عوضش کن (صفحه‌ی اصلی ← نام وبلاگ).
- **ویرایش صفحه‌ی اصلی از پنل**: بالای پنل «صفحه‌ی اصلی» رو بزن. تیتر و متن بالای سایت، عنوان لیست نوشته‌ها، شعار، متن پایین سایت و توضیح گوگل رو می‌تونی عوض کنی، با پیش‌نمایش زنده. می‌تونی بخش متن بالا رو هم کلاً مخفی کنی.
- **هایلایت دلخواه**: توی ویرایشگر یه تکه از متن رو انتخاب کن و روی یکی از چهار دایره‌ی رنگی (زرد، صورتی، سبز، آبی) بزن. دوباره همون رنگ رو بزنی هایلایت برداشته می‌شه. «بدون هایلایت» هم هست. پررنگ، کج و لینک هم داری. Ctrl+Z کار می‌کنه.
- **تگ مثل وردپرس**: توی ستون کناری، «برچسب‌ها»، تگ بنویس و Enter بزن. تگ‌های قبلی به‌صورت پیشنهاد نشون داده می‌شن. هر تگ یه صفحه‌ی مخصوص داره (`/tag/نام-تگ`) و توی صفحه‌ی اصلی هم نمایش داده می‌شه.
- **سئو**: برای هر نوشته توضیح کوتاه گوگل، عکس شاخص و نشانی (اسلاگ) داری، با پیش‌نمایش شبیه نتیجه‌ی گوگل و چند نکته‌ی راهنما. سایت‌مپ (`/sitemap.xml`) و `robots.txt` خودکار ساخته می‌شن و هر نوشته اطلاعات ساختاریافته برای گوگل داره.

## نکته‌ها

- عکس‌ها فعلاً با **آدرس اینترنتی** اضافه می‌شن (آپلود مستقیم عکس هنوز نداریم).
- تغییر رمز: کلادفلر ← پروژه ← Settings ← Variables and Secrets ← `ADMIN_PASSWORD` ← Edit. بعد از ذخیره، دوباره Deploy می‌خواد.
- ۵ بار رمز اشتباه = ۱۵ دقیقه قفل شدن ورود.
- اگه بیلد قرمز شد، متن خطا (Build log) رو بفرست.
